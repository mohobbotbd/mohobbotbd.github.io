# Mohobbot Hossen - Professional Portfolio

Welcome to the repository for my professional portfolio website. This project is designed to showcase my expertise as a Support Engineer, System Administrator, and Data Center Specialist.

## Features
- **Responsive Design**: Built with Bootstrap 5 to ensure full compatibility across mobile devices, tablets, and desktops.
- **Modern UI/UX**: Features a custom dark/light theme, glassmorphism UI elements, and scroll-reveal animations.
- **Light/Dark Mode**: Built-in theme toggler that respects system preferences.
- **Fully Static**: Developed purely with HTML, CSS, and JS, making it extremely fast and simple to host on platforms like GitHub Pages.

## Sections Included
- **Home**: Hero section with quick links and professional title.
- **About Me**: Detailed professional objective and categorized skill badges (Hardware, Networking, Security).
- **Experience**: Timeline showcasing professional roles and impact.
- **Education**: Detailed academic background.
- **Gallery**: Image placeholders for field work and certifications.
- **Contact**: Easy-to-read contact information grid.

## Setup & Deployment
This website is ready to be hosted out-of-the-box using GitHub Pages. 
A GitHub Actions workflow is included to handle automated deployment whenever changes are pushed to the `main` or `master` branch.

### Local Development
No build tools (like npm or Node.js) are required to run this project. Simply clone the repository and open `index.html` in any web browser:
```bash
git clone https://github.com/mohobbotbd/mohobbotbd.github.io.git
cd mohobbotbd.github.io
# Open index.html in your browser
```
